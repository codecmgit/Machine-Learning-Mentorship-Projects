The projects demonstrate practical implementation of:

* 📉 Model Evaluation

# 📂 Projects Included

## 🚶 Internship Project 1 – Human Action Detection

### 🎯 Objective

To classify different human activities using sensor-based data collected from wearable devices and smartphones.

### 🛠 Techniques Used

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Decision Tree Classifier
* RobustScaler
* Confusion Matrix Analysis
* Classification Report

### 📈 Outcome

Successfully classified multiple human activities and compared model performances to identify the most effective classification algorithm.

---

## 🚲 Internship Project 2 – Bike Sharing Demand Prediction

### 🎯 Objective

To predict bike rental demand based on weather conditions, seasonal factors, and environmental attributes.

### 🛠 Techniques Used

* Linear Regression
* Recursive Feature Elimination (RFE)
* MinMax Scaling
* Correlation Analysis
* Feature Selection
* R² Score Evaluation

### 📈 Outcome

Built a regression model capable of estimating bike rental demand and analyzed the impact of different environmental factors.

---

## 🩺 Capstone Project – Predict Diabetes with Machine Learning

### 🎯 Objective

To predict whether a patient is diabetic or non-diabetic using medical diagnostic measurements.

### 🛠 Techniques Used

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Decision Tree Classifier
* StandardScaler
* Classification Metrics
* Confusion Matrix Visualization

### 📈 Outcome

Developed machine learning classification models and identified the best-performing algorithm for diabetes prediction.
